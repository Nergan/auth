# auth — инструкции для AI-агентов

Сессия без пароля: запрос подписывается ключом, сервер проверяет подпись и анти-replay. Каноническая строка собирается в `app/domain/crypto_core.py`. Тесты — `pytest tests/test_auth.py`.

Это не клиент Netlazy и не его хранилище профилей. Туда не переноси правила ML-DSA и `user_id` из cutaway.

## Опыт

Если по ходу задачи стало ясно то, что в следующий раз сэкономит неверный ход, допиши это в этот `AGENTS.md`. Ход работы и разовую ошибку не копируй. Неверную старую строку поправь, а не оставляй вторую рядом.


## Скиллы

Перед багфиксом открой https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md. Короткий diff не отменяет проверку подписи и анти-replay.

## Правила

- Формат канонической строки и нормализация host, path, query и content-type — контракт клиентов. Менять их только вместе с тестами и `client_example.py`.
- Секреты, ключи и `.env` не печатать и не коммитить.
- Коммит и пуш — только когда владелец прямо просит.
- EC-ключ регистрация отвергает. Не ослабляй это, чтобы «прошёл новый алгоритм», пока задача этого не просит.
